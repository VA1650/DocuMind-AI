# 🧠 DocuMind AI

Локальный ИИ-ассистент для анализа проектной документации и репозиториев. Проект построен на связке **Spring Boot 3**, **LangChain4j**, **HTMX** и **Ollama**, что позволяет анализировать кодовую базу и вести контекстный диалог с Llama 3 полностью локально, без отправки конфиденциальных данных в облако.

## 🛠 Технологический стек
* **Backend:** Java 21, Spring Boot 3.x, LangChain4j (0.31.0)
* **Frontend:** HTML5, Tailwind CSS, HTMX (1.9.10) — асинхронный чат без тяжелых JS-фреймворков
* **LLM Engine:** Ollama (локальный запуск моделей на GPU/CPU)

---

## 🚀 Быстрый старт

### 1. Подготовка окружения (Ollama)
1. Установите [Ollama](https://ollama.com/).
2. Перенаправьте скачивание тяжелых моделей на другой диск, настроив системную переменную окружения Windows (`sysdm.cpl`):
    * `OLLAMA_MODELS` = `D:\Ollama` (или ваш путь к папке)
3. Запустите Ollama и скачайте модель Llama 3 (требуется видеокарта с $\ge$ 8 ГБ VRAM):
```bash
   ollama run llama3
```
### 2. Настройка и запуск бэкенда

  * Клонируйте репозиторий.

  * Проверьте конфигурацию в src/main/resources/application.properties:

``` 
langchain4j.ollama.chat-model.base-url=http://localhost:11434
langchain4j.ollama.chat-model.model-name=llama3
langchain4j.ollama.activation-flag=true   
```     


* Соберите и запустите проект с помощью Maven (требуется JDK 21):

```bash

mvn clean compile spring-boot:run
 ```

### 3. Использование

  * Откройте в браузере: http://localhost:8080.

  * В Шаге 1 укажите абсолютный путь к локальной папке с вашей документацией (поддерживаются файлы .md и .txt) и нажмите «Просканировать папку».

  * В Шаге 2 общайтесь с ИИ-ассистентом в чате. Система удерживает контекст предыдущих вопросов.

## 🏗 Архитектурные особенности

  *  Stateful Chat (Память диалога): В систему внедрен синглтон-компонент MessageWindowChatMemory на 20 сообщений. В отличие от стандартных stateless-скриптов, этот ассистент помнит, о чем шла речь в прошлых репликах (можно использовать местоимения вроде «расскажи о нем подробнее»).

*    On-the-Fly Prompt Injection: Архитектура Assistant полностью развязана с аннотациями. Сборка прокси-сервиса происходит динамически внутри метода контроллера на каждый запрос через systemMessageProvider. Это исключает конфликты и кэширование старых промптов, гарантируя передачу актуального датасета.

 *   UI Responsiveness: Форма отправки промптов завязана на HTMX. В момент отправки запроса интерфейс аппаратно блокирует инпут (disabled) и отображает анимированный лоадер, предотвращая спам пустых запросов во время генерации токенов локальным GPU.

  *  Clean Context Isolation: Метод загрузки репозитория рекурсивно обходит каталоги, считывает файлы и оборачивает их в строгие маркеры [FILE: имя_файла]. Это позволяет локальной Llama 3 четко видеть границы документов и не сливать их в кашу.
